# ViaHorizon 0.8.4-dev

Prepared for Horizon's native-mod publishing workflow.

## Changes

- Bundle readable GPL license text and third-party notices with the source.
- Add `horizon-registry.toml` with the registry page metadata and upstream credit.
- Add a reproducible package/submission preparation tool and publishing guide.
- Update the exact Horizon pin to `6475f62f3c834b7489e1816bf47f47ea5eb2b879`, the released Nightly checked
  for this release. Relocate hooks after Horizon's client-library split, adapt
  chat and narration formatting, and preserve the new profile skin fields.
- Retain the ViaHorizon name, short settings text and previous interaction and
  chunk-streaming fixes.

## Install

Download `viahorizon-0.8.4-dev.hnmod` and follow the
[short installation guide](../../README.md#install). Rebuild the native-mod
instance when upgrading. Existing settings retain their internal `viafabricplus`
ID. Internal hooks require the exact revisions in `compatibility.json`.

## Validation

The full Horizon client compile check passed on the pinned Nightly. All 344
Rust tests passed (46 standalone and 298 host/transport checks), including the
new inline chat/narration check and skin-override preservation assertions.
Standalone Clippy passed with warnings denied. Horizon's official package check,
registry entry check, and index build passed; packaging twice produced identical
bytes. The preparation tool also rejected a stale compile-check receipt.
See [the validation report](../validation/0.8.4/summary.json).

## Registry submission

The [publishing guide](../publishing/README.md) explains how to reproduce the
package and fill in Horizon's review form. The registry ID is `viafabricplus`;
the displayed name is ViaHorizon. The package is unsigned (signing is optional).
Preparing these files does not submit them or publish a registry listing.

See [third-party notices](../../THIRD_PARTY_NOTICES.md) for upstream credits and
[the port ledger](../PORTING.md) for known limitations. This remains a development
release with incomplete upstream behavior parity. No new in-game test was run;
this release is checked by compilation and automated protocol/package tests.
