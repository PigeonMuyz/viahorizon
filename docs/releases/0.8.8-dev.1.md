# ViaHorizon 0.8.8-dev.1

This fork's November 11, 2026 patch is based on [ViaHorizon 0.8.8-dev](https://github.com/hhhhsffd/viahorizon/releases/tag/v0.8.8-dev). It fixes a disconnect when translating a Minecraft Java Edition 1.21.11 entity metadata packet containing repeated indices. The converter keeps the last value for each repeated index when the serializer matches, following vanilla's final state.

## Install

Download `viahorizon-0.8.8-dev.1.hnmod`, extract it, then rebuild your native-mod instance with Horizon Launcher. This package targets Horizon Nightly `nightly-2026-11-08-fdc87ae` (Horizon 26.3). The package contains Rust/TOML source, the GPL-3.0-or-later license, and third-party notices.

```sh
python3 -m zipfile -e viahorizon-0.8.8-dev.1.hnmod viahorizon-0.8.8-dev.1
horizon-launcher native-build ./viahorizon-0.8.8-dev.1 --trust-native-code
```

## Validation

The injected Horizon protocol tests cover repeated fields, conflicting serializers, and truncated values. The native client was rebuilt on macOS, then confirmed working on a 1.21.11 multiplayer server that supplies a resource pack.
