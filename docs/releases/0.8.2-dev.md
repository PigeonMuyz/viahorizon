# ViaFabricPlus Native 0.8.2-dev

Unofficial GPL-3.0-or-later native Rust port for Horizon 26.3. This development
release enables Release server targets from 1.7.2 through 26.3; older releases,
snapshots, Bedrock, Beta, Alpha and Classic are outside the implemented range.

## Changes

- Remove game-thread waits behind legacy chunk translation using atomic
  connection capability snapshots and an ordered, bounded background sender.
- Retain the 0.8.1 fix for disconnects when right-clicking air on 1.7.2 servers.
- Retain server-authoritative block prediction fixes for older servers.

## Validation

255 Rust checks passed: 46 standalone and 209 host/transport checks. Live vanilla
validation passed 15 interaction/gameplay checks on 1.7.2 and 12 gameplay checks
on 1.19.2 with Auto targeting. An initial 1.19.2 Auto attempt timed out while
compilation ran; the isolated rerun passed.

In a matched 1.7.2 exploration workload at six chunks, 1280x720 and a 120 FPS cap
on an RTX 2080, the p99 frame time changed from 201.7 ms to 9.1 ms. Performance
varies with hardware, settings and server workload. See [the performance
report](../PERFORMANCE.md) and [public validation data](../validation/0.8.2/).
Older compatibility matrices describe the specific versions recorded in them;
they are not a fresh full-matrix certification of this release.

## Installation

Download `viafabricplus-0.8.2-dev.hnmod` and its checksum. This is a source bundle;
Horizon Launcher compiles it into a separate native-mod instance. Follow the
[README installation instructions](../../README.md#install). No prebuilt game
client, Minecraft assets, Java runtime or account data are included.

Turn the mod ON, select Auto or a supported target, and leave Configuration
preview OFF. Start online-mode games through Horizon Launcher with your account
selected. Rebuild an existing modded instance when upgrading.

## Known limitations

This is a development release, with incomplete ViaFabricPlus behavior parity.
Custom server extensions, some advanced item conversions, older pick-item
emulation and signed command arguments such as `/msg` and `/me` remain
incomplete. See [the port ledger](../PORTING.md). Native source hooks pin the
Horizon and horizon-mixins revisions in `compatibility.json`.
