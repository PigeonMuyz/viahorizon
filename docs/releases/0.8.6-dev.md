# ViaHorizon 0.8.6-dev

New configurations now default to **Auto** server version detection. Previously,
the mod defaulted to Native 26.3, which could cause older servers to reject the
client until a target was selected manually.

Saved targets and per-server overrides are preserved when upgrading. If your
existing target is Native 26.3, select **Options > Mods > ViaHorizon > Settings >
Server target: Auto detect** once. Keep Configuration preview OFF to play.

Download `viahorizon-0.8.6-dev.hnmod` and follow the
[installation instructions](../../README.md#install). Replace the old package
and rebuild the native-mod instance. Horizon and horizon-mixins compatibility
pins are unchanged.

## Validation

47 standalone tests, 299 host/transport tests, strict Clippy,
the Horizon client compile check, package and registry checks passed.
Packaging is reproducible. See the [validation summary](../validation/0.8.6/summary.json). No additional
in-game test was run for this default-setting change.
