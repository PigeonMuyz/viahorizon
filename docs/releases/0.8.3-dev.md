# ViaHorizon 0.8.3-dev

ViaHorizon lets you choose the Minecraft server version when playing with Horizon.
This development release introduces the new name and simplifies the mod settings.

## Changes

- Rename the mod to ViaHorizon in the Mods list, chat messages, errors and launcher
  instance. Package downloads now use the `viahorizon` name.
- Replace the old Mods description with a short explanation of server version
  selection. Remove the outdated translation-range text from settings and status.
- Add `/vh` and `/viahorizon` commands. Existing command aliases and saved settings
  continue to work.
- Retain the 0.8.2 chunk-streaming fixes and the earlier interaction fixes.

## Installation

Download `viahorizon-0.8.3-dev.hnmod` and its `.sha256` checksum, then follow the
[installation instructions](../../README.md#install). Rebuild your native-mod
instance when upgrading, restart the launcher and game, and enable ViaHorizon.
Select Auto or a server version and leave Configuration preview OFF to play.

The internal mod ID and configuration directory remain `viafabricplus` so your
existing settings and per-server overrides carry over.

## Validation

Production client rebuild, 46 standalone tests, 209 host/transport tests and
strict Clippy checks passed. The launcher wrapper passed its help-command check.
No additional in-game test was run for this menu/branding change. See the
[validation summary](../validation/0.8.3/summary.json).
